# Roadmap

Direction is set by the [product definition](docs/PRODUCT.md). Completed work
is recorded in the [changelog](CHANGELOG.md).

## Now — v32 "Refocus"

Give the application a clear purpose: tweaks first.

- [x] Product definition and simplified documentation
- [x] Retire the release-evidence tooling that was not part of the product
- [ ] One navigation model with Tweaks as the start page
- [ ] Simple mode by default; advanced tools behind one switch
- [ ] Remove hidden pages, dead modules, and unused CLI domains
- [ ] Data-driven tweak catalog, growing from 22 to 50+ tweaks
- [ ] Per-tweak reset to default, undo, and "changed from default" filter

## Next

- More desktop coverage: GNOME and KDE file-manager and window behavior
- DNF/system tweaks: mirrors, automatic updates, Flathub, RPM Fusion and codecs
- Shareable tweak profiles (export and re-apply)

## Later

- Additional Fedora spins and Atomic desktops, as qualification allows

## Not planned

System monitoring as a headline feature, mesh/network sharing, AI features,
and a plugin marketplace.
