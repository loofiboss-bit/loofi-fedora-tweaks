# Companion 32.5.0 — local candidate

Companion brings personal configuration, application access explanations, and
Fedora guidance into the existing control center. KDE on DNF5 is the primary
target; optional GNOME counterparts and Atomic limitations remain explicit.

- Keep a local profile library, review shared profiles, and use Focus, Privacy
  basics, or Touchpad comfort through the existing verified setting workflow.
- Inspect declared Flatpak access separately from installation/current-user
  overrides, then open an installed permission tool for changes.
- Compare saved Health sessions and preserve missing evidence as not comparable.
- Inspect screen-sharing infrastructure without recording or restarting services.
- Prepare a masked, editable support question for local Markdown or ZIP export.
- Review local package health, sources, storage, reboot advice, and a manual
  backup checklist before following the official Fedora upgrade instructions.

See [qualification](../COMPANION_VERIFICATION.md) for dated automated evidence
and physical checks. This source candidate does not imply installation or publication.

## KDE appearance extension

Companion adds installed pointer themes, requested pointer size, and Plasma
styles to the 79-control catalog. They share global search, favorites, CLI,
profiles and verified restoration. Pointer theme/size changes preserve the other
key; a separate source-bound notification reports delivery without claiming
visual verification. KDE X11 offers native Cursor Settings. Theme installation,
global theme application and broader platform qualification are outside this
extension.
