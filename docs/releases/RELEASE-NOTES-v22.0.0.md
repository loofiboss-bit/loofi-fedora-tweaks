# Release Notes -- v22.0.0 "Alignment"

**Release Date:** 2026-07-28
**Codename:** Alignment
**Theme:** Fedora-native consolidation and truthful depth

## Summary

Alignment makes existing Fedora workflows easier to trust and navigate. It
strengthens release/runtime correctness, delegates Plasma-owned configuration
to native tools, and reduces visual decision density without changing public
interfaces or stored user data.

## Highlights

- Fail-closed COPR qualification and corrected RPM runtime dependencies.
- Exact 81-route catalog decomposition with five safe Plasma handoffs.
- One-next-action Home and Action Center presentation.
- Expanded SecretStore and accessibility evidence.

## Changes

### Changed

- Destination-owned catalog modules and quieter core workflows.

### Added

- Native handoff contracts, GitHub artifact attestations, and V22 matrices.

### Fixed

- Flatpak detection, bounded shutdown, and credential redaction gaps.
