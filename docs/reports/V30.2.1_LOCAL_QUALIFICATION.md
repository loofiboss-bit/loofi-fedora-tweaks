## Package procedure

RPM identity: `1:30.2.1-1.fc44.noarch`. Build with `just build-rpm` and retain
the generated source RPM as well as the binary RPM. Build the Python source
distribution with `just build-sdist`. Local unsigned build artifacts are not
COPR packages or published release assets.

Install the RPM in an ephemeral rootless Podman Fedora 44 container, create
an ordinary disposable `smoke` user, and run:

```bash
python3 /workspace/scripts/package_smoke.py --launcher /usr/bin/loofi-fedora-tweaks
```

The smoke launches installed `--cli --json info` and `--cli --json doctor`,
checks finite JSON and exact maintained fields/types, and checks exit-status
consistency. A doctor result with explicitly unavailable tools and exit 1 is
a valid inspection result, not proof of healthy hardware or session services.
XDG directories and Python import paths are isolated. HOME is unchanged; the
existing startup log remains inside the disposable user's container home.
Verify installed package integrity and compare installed payload identity
against the mounted RPM. The installed RPM SHA256 header matched the local artifact:

```text

```

`rpm -V loofi-fedora-tweaks` passed inside the container. Both installed JSON
contracts passed; doctor reported its critical dependencies available. This
